Inventory Management System 
Full stack inventory management application built with ASP.NET Core Web API and SQL Server 

Tech Stack 
-ASP.NET Core Webb API (.NET 8)
-SQL Server + Entity Framework Core 
-HTML,CSS,Javascript (Frontend)

Features
-Product management with stock tracking
-Supplier management
-Purchase recording with automatic stock increases
-Sales recording with automatic stock decreases 
-Low stock report
